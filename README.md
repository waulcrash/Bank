## 🚀 Основные возможности Calculator

- **Прескоринг** — первичная проверка данных заявки (сумма, срок, возраст, паспортные данные)
- **Скоринг** — расширенная проверка клиента (возраст 21-65 лет, паспортные данные)
- **Генерация 4-х кредитных предложений** с разными комбинациями:
  - Без страхования и зарплатного статуса
  - Только страхование
  - Только зарплатный статус
  - Страхование + зарплатный статус
- **Расчет аннуитетного платежа** по формуле сложных процентов
- **Формирование графика платежей** с детализацией по месяцам
- **Расчет ПСК** (полной стоимости кредита) в процентах

## 📐 Логика расчета

### Генерация предложений (OfferService)

Сервис генерирует 4 варианта кредитных предложений на основе входных данных:

1. **Страхование (insurance)**: 
   - Уменьшает процентную ставку на величину `insurance.discount` из конфигурации
   - Увеличивает сумму кредита на стоимость страховки
   - Стоимость страховки = (сумма кредита / 1_000_000) × `insurance.costPerMillion`

2. **Зарплатный статус (salary)**:
   - Уменьшает процентную ставку на величину `salary.discount` из конфигурации

3. **Расчет ежемесячного платежа**:
    - Месячная ставка = (Годовая ставка / 12) / 100
    - Коэффициент аннуитета = (Мес.ставка × (1 + Мес.ставка)^срок) / ((1 + Мес.ставка)^срок - 1)
    - Ежемес. платеж = Сумма кредита × Коэффициент аннуитета

### Полный расчет кредита (CreditCalculationService)

Используется после успешного скоринга для финального расчета:

1. **Расчет финальной ставки**:
    - Ставка = Базовая ставка - страховой дисконт (если есть) - зарплатный дисконт (если есть)

2. **Расчет общей суммы**:
    - Сумма = Запрошенная сумма + стоимость страховки (если включена)

3. **Создание графика платежей**:
- Проценты за месяц = Остаток долга × Месячная ставка
- Погашение долга = Ежемесячный платеж - Проценты
- В последний месяц корректировка для полного погашения

4. **Расчет ПСК**:
    - Переплата = (Ежемес.платеж × Срок) - Сумма кредита
    - ПСК = (Переплата / Сумма кредита) × 100%

### Прескоринг (PrescoringService)

Первичная валидация заявки:

| Поле | Требования |
|------|------------|
| Сумма кредита | от 10 000 до 10 000 000 рублей |
| Срок кредита | от 6 до 60 месяцев |
| Имя/Фамилия | только буквы, 2-30 символов |
| Email | корректный формат |
| Возраст | от 18 до 70 лет |
| Паспортные данные | серия — 4 цифры, номер — 6 цифр |

### Скоринг (ScoringService)

Расширенная проверка для финального расчета:

| Поле | Требования |
|------|------------|
| Возраст | от 21 до 65 лет |
| Паспортные данные | серия — 4 цифры, номер — 6 цифр |
| Сумма/срок | должны быть положительными |

## ⚙️ Конфигурация

Конфигурация параметров кредитования находится в `CreditProperties`:

```java
public class CreditProperties {
    // Базовая процентная ставка
    private BigDecimal baseRate = BigDecimal.valueOf(15.0); 
    
    private Insurance insurance = new Insurance();
    private Salary salary = new Salary();
    
    @Data
    public static class Insurance {
        //Скидка за страхование (%)
        private BigDecimal discount = BigDecimal.valueOf(3.0); 
        // Стоимость страховки за миллион рублей
        private BigDecimal costPerMillion = BigDecimal.valueOf(100000); 
    }
    
    @Data
    public static class Salary {
        //Скидка за зарплатный статус (%)
        private BigDecimal discount = BigDecimal.valueOf(1.0);
    }
}
```
